Codex

疑問から質問ノートができるまで

「質問」と投げた疑問を、一次情報に基づく図解つきHTMLへ変換し、確認後に公開する。

2026.07.23 · 5 min read

要点: 調査・記録・索引づけを一つの依頼にまとめると、その場の理解を検索可能な資産に変えられる。

全体の流れ

ノート作りは四段階です。Codexは記事の追加までは進めますが、公開は人が差分を確認してから行います。

1. 質問スマホやPCから、気になったことを自然文で送る。
2. 調査公式文書や仕様などの一次情報を確認する。
3. 記事化図解、例、注意点、参照元をHTMLにまとめる。
4. 確認・公開人が差分を読み、問題がなければGitHub Pagesへ出す。

使い方

このプロジェクトをCodexで開き、たとえば次のように依頼します。

質問 HTTPキャッシュのETagとLast-Modifiedはどう使い分ける？

個人スキル instant-tech-notes が反応し、質問の分野に合った情報源、カテゴリ、URLを決めて記事を追加します。索引にも同時にカードを足すため、後からキーワードで探せます。

安全に続けるための境界

  • 記事には公開してよい情報だけを含める。
  • 技術的な主張は一次情報で確かめ、参照URLを残す。
  • AIが作った内容をそのまま公開せず、人が差分を確認する。
  • スキルはpushや公開を勝手に行わない。
