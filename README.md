# Question Notes

Codexと一緒に育てる、ビルド不要の静的HTML質問ノートです。技術だけでなく、科学、歴史、社会、仕事、文化、暮らしなど、分野を問わず使えます。

Codexへ `質問 なぜ〜？` のように送ると、個人スキル `instant-tech-notes` が分野に合った情報源を調べ、分かりやすい記事を追加します。公開前には必ず差分を確認してください。

ローカル確認:

```sh
python3 -m http.server 8000
```

その後 `http://localhost:8000` を開きます。

GitHub Pagesでは、リポジトリの Actions を有効にすると `.github/workflows/static.yml` が自動で配信します。
